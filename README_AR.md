# حقوقي السوري — مشروع موقع ويب أولي

## ما الذي يحتويه المشروع؟
- واجهة عربية متجاوبة للهاتف والكمبيوتر.
- مساعد قانوني يستدعي مساراً خلفياً `/api/ask` عند نشره على Vercel.
- مكتبة ملخصات تجريبية ونموذج إضافة محلي.
- مخطط SQL أولي لقاعدة بيانات Supabase.
- تنبيهات واضحة أن الإجابات التعليمية تحتاج التحقق من النصوص الرسمية.

## ما الذي لا يعمل قبل الإعداد؟
- الذكاء الاصطناعي الحقيقي لن يعمل حتى تضبط `AI_API_KEY` و`AI_API_URL` في إعدادات البيئة لدى خدمة الاستضافة.
- نشر الملخصات لجميع الطلاب ليس مفعلاً في الواجهة الحالية؛ الإضافات محلية فقط. يلزم ربط Supabase Auth + Database + Storage وتطبيق سياسات الصلاحيات في `supabase/schema.sql`.
- لا يوجد عنوان موقع منشور بعد؛ هذه ملفات مشروع وليست موقعاً منشوراً.

## تشغيل من الهاتف فقط
1. حمّل ZIP إلى هاتفك واستخرج الملفات.
2. أنشئ حساباً في GitHub من متصفح الهاتف.
3. أنشئ مستودعاً جديداً وارفع ملفات المشروع.
4. افتح Vercel واربطه بمستودع GitHub لنشر الموقع. قد تختلف الشاشات حسب واجهة الخدمة.
5. في إعدادات المشروع على Vercel، أضف متغيرات البيئة:
   - `AI_API_URL`: عنوان API المتوافق مع OpenAI الذي تختاره.
   - `AI_API_KEY`: مفتاح الخدمة السري (لا تضعه داخل `public/` أو `app.js`).
   - `AI_MODEL`: اسم النموذج المدعوم من مزودك.
6. أعد النشر، ثم اختبر المساعد. يرسل الخادم السؤال للمزود ويعيد الجواب؛ لم يتم تضمين مفتاح أو مزود مدفوع في هذه الحزمة.

## قاعدة البيانات ومشاركة الملخصات
1. أنشئ مشروعاً في Supabase.
2. نفّذ `supabase/schema.sql` في SQL Editor.
3. اضبط مصادقة المستخدمين، ثم أضف ربط العميل وسياسات Row Level Security قبل تفعيل الرفع العام.
4. يجب أن يكون للطلاب والمشرفين أدوار محددة. لا تثق بدور يرسله المتصفح بنفسه؛ يجب تعيين صلاحيات المشرف من قاعدة البيانات.
5. لإتاحة ملفات PDF تحتاج Storage bucket وسياسات قراءة/رفع وحجم ملف مناسب ومراجعة للمحتوى.

## عقد API
`POST /api/ask`
```json
{ "question": "ما الفرق بين القانون العام والخاص؟", "year": "الأولى" }
```
الاستجابة:
```json
{ "answer": "نص الإجابة", "sources": [] }
```
المسار يتطلب `AI_API_URL` و`AI_API_KEY` و`AI_MODEL` ويستخدم واجهة chat completions المتوافقة مع OpenAI. راجع توثيق مزودك وتكلفته وسياسة البيانات.

## الأمان والدقة
- لا تدخل بيانات شخصية حساسة أو وقائع قضايا سرية في المساعد.
- الإجابات ليست استشارة قانونية.
- لا تعرض أي مادة أو رقم مادة على أنه رسمي دون مصدر موثوق وتاريخ تحديث.
- لا ترفع ملخصات محمية بحقوق نشر دون إذن.
